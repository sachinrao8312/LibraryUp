# LibraryUp

Android app for owners of self-study libraries and reading rooms: seats by shift,
students, monthly fees with WhatsApp reminders and receipts, attendance, expenses and
profit. Offline-first; the library's data stays on the owner's phone and their own
Google Drive backup.

- Product, research and decisions: [`CLAUDE.md`](CLAUDE.md)
- What's next: [`TASKS.md`](TASKS.md)
- Build: `./gradlew :domain:test :app:assembleDebug` (needs `app/google-services.json`)

Started from the RentUp codebase (`ai.sach.rentup`); package `ai.sach.libraryup`.
